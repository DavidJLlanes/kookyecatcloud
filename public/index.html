Acceso WebDAV

Monta tu nube como una unidad de red, o haz que el móvil suba las fotos solo

—
  • Windows — Explorador → Este equipo → Conectar a unidad de red → pega la dirección
  • macOS — Finder → Ir → Conectarse al servidor (⌘K) → pega la dirección
  • Android — FolderSync o similar: tipo WebDAV, esa dirección y tu usuario

Entra con tu usuario y tu misma contraseña, o con un token de aplicación creado desde Cuenta. Ves exactamente lo mismo que en la web.
